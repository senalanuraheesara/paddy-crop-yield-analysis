# Paddy Crop Yield Analysis

## Project Overview

This project analyses historical paddy production data
to identify factors affecting crop yield and develop
statistical prediction models.

## Problem Statement

Agricultural organizations require reliable yield
analysis to support production planning and resource
allocation.

## Dataset

Source:
Sri Lanka Paddy Statistics

Dataset contains:
- District
- Season
- Sown extent
- Harvested extent
- Yield
- Production

## Objectives

1. Analyse yield patterns
2. Identify factors affecting yield
3. Build prediction models
4. Provide agricultural insights

## Models

- Multiple Linear Regression
- Ridge Regression
- LASSO Regression

## Tools

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook
